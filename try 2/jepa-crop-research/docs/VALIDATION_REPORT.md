## 6. What remains unverified, and external prerequisites

- **PASTIS format.** File names, the `(T,10,H,W)` layout, `TARGET[0]` semantics, the `dates-S2` format and the parcel-ID files come from my recollection of the official loader. The synthetic data exercises the parser *in the assumed format only*. Section 4 stops with a diagnostic if your copy differs.
- **Band order and NDVI.** Checked by the Section 5.4 plausibility gate on your data.
- **GPU path.** bf16 autocast, the fp16 `GradScaler` branch, `torch.cuda.OutOfMemoryError` handling, GPU-resident data and peak-memory accounting were not executed. The code paths exist but are untested here.
- **Runtimes.** Every runtime figure in README §6 is a planning estimate. Cell 11.3 replaces it with projections from throughput measured on your GPU.
- **Windows.** Not tested. The code avoids worker processes and shell commands and uses `pathlib`, but Random Forest uses a joblib process pool (`n_jobs=-1`).
- **Literature.** None of the citations in AUDIT_REPORT.md was checked against primary sources in this session.
